\## Overview

This network topology models the core IT infrastructure for a hotel environment, providing secure network segmentation for guests, administration, front desk operations, and central servers.



\## Features \& Implementation

\- \*\*VLAN Segmentation:\*\* Segregated guest traffic from internal hotel business operations.

\- \*\*Inter-VLAN Routing:\*\* Secure communication between administrative devices and servers.

\- \*\*IP Addressing \& DHCP:\*\* Automated dynamic host configuration across subnets.

## Description

This project models an enterprise-grade campus network infrastructure designed for a modern hotel environment using **Cisco Packet Tracer**. 

The primary objective is to separate critical business operations from guest and public access while maintaining centralized administration, high availability, and secure internet connectivity.

### Key Highlights:
- **Network Segmentation (VLANs):** Logical separation between Administrative Staff, Front Desk/POS terminals, Hotel Management Servers, and Guest Wi-Fi access.
- **Traffic Security & Isolation:** Access control mechanisms configured to ensure guest users cannot reach sensitive internal databases, financial devices, or management planes.
- **Automated Addressing (DHCP):** Dynamic IP allocation across all subnets to streamline client connectivity for staff workstations and visiting guest devices.
- **Routing & Core Services:** Efficient Inter-VLAN routing allowing front desk and admin devices to communicate securely with central hotel servers (DNS, Web, Database).
